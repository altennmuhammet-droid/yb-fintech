# YB Fintech — Kurumsal Web Sitesi

**YB Fintech** (Real World Assets. Digitized.) kurumsal web sitesi.

---

## 🏛️ Şirket Konumlandırması

YB Fintech; gerçek dünya varlıklarının (RWA) tokenizasyonu, fiziksel ve finansal varlıkların dijitalleştirilmesi ve kurumsal dijital varlık altyapıları geliştiren yeni nesil bir finansal teknoloji şirketidir. 

Geleneksel bankacılık ve finansal disiplini modern dağıtık defter (distributed ledger) teknolojileriyle buluşturur.

## 🛡️ Güvenlik & Zero External Dependency

- Sitede hiçbir harici runtime bağımlılığı, üçüncü parti izleyici, canlı CDN veya hotlink bulunmamaktadır.
- Tüm partner logoları yerel /public/assets/partners/ dizinindedir.
- Tüm fontlar (Instrument Sans, Instrument Serif, Inter) yerel WOFF2 dosyaları olarak sunulur.
